Mittari is now signed with a Developer ID and notarized by Apple, so Gatekeeper no longer blocks the first launch. There's no more quarantine workaround to remember: download the DMG, drag Mittari to Applications, and open it.

This release also adds automatic updates. Mittari checks GitHub for new releases and asks, the first time it can, whether you'd like it to check automatically from then on; you can change that later in Settings. Updates download and install in the background.

The app is now a universal binary, running natively on both Apple Silicon and Intel Macs.

If you'd like to support the project, there's a new "Buy Me a Coffee" link in the menu bar item and in Settings.

Because this is the first version with an updater, it can't update itself into place: if you're on an earlier version, you'll need to download and install 1.0.0 by hand this one time. Every release after this one will offer to update automatically.

Nothing changes in what Mittari reads from your Mac. It only looks at the Claude Code and Codex logs already in your home folder, the same as before, so this update needs no new permissions and nothing to re-grant in System Settings.
