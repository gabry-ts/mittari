Choosing what Mittari shows is simpler. The Menu Bar page in Settings is now one list of the seven items: drag them into the order you like and switch off the ones you don't need, with the live preview on top. The Popover page works the same way.

The Settings window now looks like a macOS 26 sidebar window, with the close, minimize and zoom buttons inside the sidebar. Check for Updates dims while a check is running.
